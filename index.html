TrackedApps - Privacy Policy

Last updated: October 6, 2026

TrackedApps ("the App", "we", "our", or "us") is a mobile application designed to help users monitor application usage time, set usage limits, and manage selected contacts for notification and communication features.

1. Information We Access

Application Usage Information

TrackedApps may access application usage statistics when the user grants the required Android permission. This information may include:

  • Application name
  • Application package name
  • Application usage duration
  • Usage session information
  • Usage limits configured by the user

This information is used to provide usage monitoring, usage summaries, charts, and usage-limit features.

Contact Information

If the user chooses to use the contact-management features, TrackedApps may store information such as:

  • Contact name
  • Phone number
  • User-selected SMS permission for the contact
  • User-selected call permission for the contact

This information is used only to provide the contact and communication features configured by the user.

SMS and Phone Call Permissions

If the user grants the corresponding Android permissions, TrackedApps may use:

  • SMS permission to send SMS messages according to features configured by the user.
  • Phone permission to initiate phone calls according to features configured by the user.

TrackedApps does not read the user's incoming SMS messages.

2. How We Use Information

The information accessed by TrackedApps is used to:

  • Display application usage statistics.
  • Calculate daily usage summaries.
  • Display usage charts.
  • Apply user-configured application usage limits.
  • Run scheduled background usage checks.
  • Manage contacts configured by the user.
  • Send SMS messages or initiate phone calls when the user has enabled the corresponding features.

We do not use this information for advertising profiling.

3. Data Storage

TrackedApps stores application configuration, usage-related information, and contact information locally on the user's device using the application's local database and device storage.

The application does not require users to create an account.

4. Data Sharing

TrackedApps does not sell, rent, or share personal information with third parties for advertising purposes.

TrackedApps may use Google Firebase services for application functionality, such as Firebase Cloud Messaging.

Third-party services may process limited technical information according to their own privacy policies.

5. Data Security

We take reasonable measures to protect information stored by the application. However, no method of electronic storage or transmission can be guaranteed to be completely secure.

6. User Control

Users can:

  • Select which applications are monitored.
  • Configure or remove application usage limits.
  • Add, edit, or delete contacts stored by the application.
  • Grant or revoke Android permissions through device settings.
  • Uninstall TrackedApps at any time.

Uninstalling the application removes locally stored application data according to Android's application-data management behavior.

7. Children's Privacy

TrackedApps is not specifically designed for children under the age of 13.

We do not knowingly collect personal information from children through a separate online account or registration system.

8. Changes to This Privacy Policy

We may update this Privacy Policy when the application's features or data practices change.

Any updated version will be published on this page with a new "Last updated" date.

9. Contact

If you have questions about this Privacy Policy or TrackedApps' data practices, please contact the developer through the contact information provided on the application's Google Play listing.
